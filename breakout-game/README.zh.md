# 打砖块

**[简体中文](README.zh.md)** · [English](README.md)

---

经典打砖块：用挡板接住小球，打光所有砖块过关。

## 玩法

- **鼠标移动** 控制挡板（电脑）
- **← → 方向键** 控制挡板
- **手指拖动** 控制挡板（手机）
- **空格 / 回车** 发射小球、继续游戏
- 每块砖 10 分，打光一屏进入下一关

## 规则

- 小球从挡板反弹的角度取决于**击中挡板的位置**，越靠边角度越斜
- 掉一次球扣一条命，初始 3 条命
- 每过一关球速增加，关卡越高越难

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

游戏顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里，下次打开自动沿用。
