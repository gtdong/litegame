# 2048

**[简体中文](README.zh.md)** · [English](README.md)

---

经典 2048：滑动合并相同数字，凑出 2048。

## 玩法

- **方向键** 或 **WASD** 移动方块
- 触屏设备直接 **滑动**
- 相同数字相撞会合并成两倍，每次合并计入得分
- 凑出 2048 即通关，可以继续挑战更高数字
- 棋盘填满且无法移动时游戏结束

## 其他

- **撤销一步**：回退上一步操作，最多保留 20 步
- **最高分**保存在浏览器 `localStorage` 的 `game2048_best` 键下

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

游戏顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里，下次打开自动沿用。
