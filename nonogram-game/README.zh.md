# 数织

**[简体中文](README.zh.md)** · [English](README.md)

---

给格子涂色，让每一行、每一列都符合它给出的数字线索。数字表示该行/列中连续填色段的长度，按顺序排列，两段之间至少空一格。靠推理，别靠猜。

## 玩法

- **左键**循环切换格子的状态：空 → 填色 → ✕ → 空
- **右键**（触屏长按）直接标 ✕ —— 相当于自己记一句「这格肯定是空的」
- 每行每列都显示着各自的数字线索；某一整行/列被完全确定且与线索一致时，这组线索会自动变暗
- **提示**会替你填上一个答案要求的格子
- **撤销**回退一步，**重开**清空棋盘并重置计时，**换一题**重新出一道
- 快捷键：**U** 撤销 · **R** 重开 · **Esc** 关闭结算弹窗

不想被"点错了"打扰时，把**错误提示**关掉即可。

## 三种尺寸

| 尺寸 | 名称 | 手感 |
| --- | --- | --- |
| 5×5 | 新手 | 熟悉机制 |
| 10×10 | 普通 | 能认出的小图案 |
| 15×15 | 困难 | 程序生成的图形，真需要动脑 |

## 每道题都只有唯一解

这是设计红线，不是加分项。一道有两个解的数织就是猜谜游戏，而猜谜不是推理。

- **10 张手绘的 5×5 图案**和 **10 张手绘的 10×10 图案**，每一张都验证过：线索恰好只对应一个解。
- **程序生成的题目**从一个随机双轴对称图案出发，只有在线索传播求解器把整盘棋**完全推导确定**之后才会被采用。如果光靠传播就能定下每一格，那这个解就是可证明的**唯一解**。
- 所以棋盘从不说谎：你要找的答案，永远能靠逻辑推出来。

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

游戏顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里，下次打开自动沿用。

## 测试

`node tools/nonogram-test.js` —— 157 项断言。除了常规的规则校验（线索生成、点击循环、线索自动划掉、撤销、胜利判定），还专门把求解器本身钉死：

- **枚举出的每一种排列都必须真的符合它对应的线索**，且不重复 —— 这是针对一个「脏尾巴」bug 的定向回归测试：它曾让枚举器吐出属于**别的**线索的排列（例如 `[1,1]` 会产出 `01011`，而它的线索其实是 `[1,2]`）；
- 每张内置图案都必须恰好一个解，**并且**求解器给出的答案必须和图案本身完全一致；
- 每道生成的题目都必须唯一，且能通过求解器原样复现；
- 完整通关流程通过模拟 DOM 里的**真实开始按钮和真实格子点击**跑通；反向校验组会把已知 bug 重新注入，证明这些断言确实会失败。
