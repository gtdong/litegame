# 数独

**[简体中文](README.zh.md)** · [English](README.md)

---

经典 9×9 数独，三档难度。每道题都是即时生成，并保证**唯一解**。

## 玩法

- 点击（或轻触）选中格子，按数字键或点屏幕下方的数字输入
- 每一**行**、每一**列**、每个 **3×3 宫**都要填入 1–9，不能重复
- 方向键移动选择，`Backspace` / `Delete` 清空格子
- 按 **N** 或点「笔记」按钮切换笔记模式，在空格里记铅笔小字
- 填错会立刻标红（行 / 列 / 宫内出现重复）
- **错误计数器**记录与正解不一致的输入次数

## 难度

| 难度 | 提示数 |
|---|---|
| 简单 | 约 43 |
| 中等 | 约 35 |
| 困难 | 约 29 |

出题方式：先生成一张完整终盘，再逐格挖洞——只有挖掉后仍然**唯一解**才保留，所以每道题都可以纯靠逻辑推出。

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

游戏顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里，下次打开自动沿用。
