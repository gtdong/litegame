# 太空侵略者

**[简体中文](README.zh.md)** · [English](README.md)

---

经典街机游戏的重制版。一支 11 × 5 的侵略者大军左右横向行进，每碰到一次边界就整体**下移一格**——而且**存活越少，移动越快**。在它们抵达你的防线之前全部消灭，躲在 4 座**可逐块破坏**的护盾后面，并在奖励 UFO 横穿顶部时把它打下来。3 条命，无限波次。

## 玩法

- **方向键 / A D** 左右移动飞船（按住可持续移动）。**空格 / 方向键上 / W / Enter** 开火。触屏设备用界面上的 ◀ ▶ 与**开火**按钮。
- **屏幕上限一颗子弹**（经典规则）：上一颗子弹命中目标或飞出屏幕后，才能再次发射。
- **敌阵是离散步进移动的。** 每一步整体横向挪动一点；当队形边缘碰到边界时整体**下移一格**并反向。随存活数量减少，步进间隔缩短，于是最后一只会飞快地横扫屏幕。
- **护盾逐块剥落。** 4 座护盾各自是一张位图，玩家的子弹（自下而上）与敌方的炸弹（自上而下）都会一点点啃掉它，形成可以被穿过、也可能被击穿的缺口——**不是**「有/无」的整座开关。
- **UFO** 在敌阵还较多时周期性横穿顶部；击落可获得一个随机（但由 seed 决定）分值：50 / 100 / 150 / 300。
- **敌方炸弹**由所选列中最下方的一只存活侵略者投下。被炸弹命中损失一条命，敌阵会回到起始姿态，游戏继续。
- **若敌阵抵达防线，则入侵成功、游戏立即结束**（经典规则）。
- **P** 键或界面按钮可暂停。

## 计分

| 事件 | 分数 |
|---|---|
| 击落**顶行**侵略者 | +30 |
| 击落**中间行**侵略者（第 1–2 行） | +20 |
| 击落**底部行**侵略者（第 3–4 行） | +10 |
| 击落 **UFO** | +50 / +100 / +150 / +300（由 seed 决定的随机值） |
| 清空一波 | 300 + 100 × 波次 |

## 棋盘

游戏区为 **480 × 560** 逻辑像素。所有几何都由 `CELL` / `COLS` / `ROWS` / `FIELD_W` / `FIELD_H` 常量决定，绝不从 canvas 反推。

| 元素 | 布局 |
|---|---|
| 侵略者大军 | 11 列 × 5 行，每只占一个 `CELL`（28 px） |
| 各行外形 | 第 0 行 → `A`，第 1–2 行 → `B`，第 3–4 行 → `C` |
| 护盾 | 4 座，每座 22 × 16 格，每格 2 px，中心位于 x = 60 / 180 / 300 / 420 |
| 玩家飞船 | 40 × 22 px，中心位于 y = 500 |
| 防线 | 敌阵底部抵达 y = 470 即判负 |

## 波次

每一波起始位置更**低**、行进更**快**：

| 参数 | 第 1 波 | 每增加一波 |
|---|---|---|
| 敌阵顶部 y | 48 | +6 / 波（上限 88） |
| 最慢步进间隔 | 0.50 s | −0.02 s（下限 0.36 s） |
| 最快步进间隔 | 0.15 s | `stepBase × 0.3` |
| UFO 周期 | 40 步 | −3 步（下限 20） |

`stepInterval(aliveCount, wave)` 依据存活数量在最慢与最快之间线性插值：第 1 波下 55 只存活 → 0.500 s，25 只 → 0.309 s，1 只 → 0.156 s。

### 每一波都保证可完成

两个难度旋钮（起始更低、步进更快）都在消耗玩家的**步数额度**，而在「屏幕上限一颗子弹」的规则下击杀速率又被子弹飞行时间限制。为保证任意一波都可通关，敌阵在被击落到防线前拥有的**预算步数**被维持在「理想玩家清空 55 只所需步数」之上，且子弹足够快（800 px/s）以压低这个需求量：

| 波次 | 预算步数 | 理想玩家（50% 命中） | 比值 |
|---|---|---|---|
| 1 | 769 | 190 | 4.05 |
| 4 | 699 | 211 | 3.31 |
| 8 | 629 | 248 | 2.54 |
| 12 | 629 | 248 | 2.54 |

比值随波次增加而下降，但始终远离 1，因此第 1–12 波全部可达。一个刻意浪费约 60% 子弹的「手残」bot 也能清空第 1–8 波。

## 确定性

每一只侵略者的位置都是**步数的纯函数**——`formationState(steps, aliveCount, wave)` 返回 `{ offsetX, originY, dir }`；任何逐帧的浮点位置都不会被累加，因此任意步数都可被精确复算。步进的时间间隔也是纯函数 `stepInterval(aliveCount, wave)`。

所有随机性（炸弹投向哪一列、UFO 携带多少分）都来自 `(seed, counter)` 的**带种子**伪随机函数——**全程没有 `Math.random()`**。种子及其计数器都保存在游戏状态里（`getState().rng`）并作为参数暴露，因此 `newGame({ seed })` 完全可复现，而不同 seed 会产生不同、但各自可复现的炸弹与 UFO 序列。玩家飞船与子弹按时间平滑插值绘制；侵略者则离散步进（经典表现）。

`draw()` 之外没有任何代码会改动状态，因此无帧驱动的步进运行与屏幕上的游戏严格同步。

## 测试桥接

页面在 `window.SI` 上暴露了机器可读的模型：

- **常量：** `COLS`、`ROWS`、`CELL`、`FIELD_W`、`FIELD_H`
- **纯几何 / 计分：** `waveConfig(wave)`、`stepInterval(aliveCount, wave)`、`formationState(steps, aliveCount, wave)`、`scoreFor(kind, row)`、`ufoScoreAt(seed, ufoIndex)`、`bombColumnFor(stepIndex, seed, aliveColumns)`、`nextRandom(state)`
- **纯护盾模型：** `bunkers()`、`bunkerBitmap(i)`、`damageBunker(bunkerIndex, x, y, radius)`、`hitTestBunker(bunkerIndex, x, y)`、`makeBunker()`
- **查询：** `invaderAt(state, index)`、`invaderBox(state, index)`、`playerBulletAt(t)`、`bulletY(y0, t)`、`bombAt(i)`、`bombs()`
- **生命周期：** `newGame(opts)`、`fire()`、`move(dir)`、`start()`、`pause()`、`tick(seconds[, step])`、`getState()`

`damageBunker` 与 `hitTestBunker` 使用**护盾局部格坐标**（横向 0..21、纵向 0..15），且都不就地修改：`damageBunker` 返回一张**新**位图，原图保持不变。`move(dir)` 接受 `-1` / `1` / `0`（或 `'left'` / `'right'`），设置的是「按住方向」，由 `tick()` 负责积分——因此 `move(1); tick(0.1)` 会让飞船恰好移动 0.1 秒。

`tick()` 不依赖任何墙钟即可确定性推进，并在推进后刷新 DOM HUD（与渲染循环每帧走的是同一套带值缓存的刷新），因此无帧驱动的运行也与屏幕上的数字保持一致。

`getState()` 返回
`{ score, lives, wave, phase, invadersLeft, rng, ship, bullets, bombs, bunkers, … }`；
其中 `bunkers` 是「仍至少保留一个实心格的护盾数量」，此外还有 `steps`、`stepInterval`、`formation`、`invaders`、`aliveColumns`、`ufo`、`bunkerSolid` 等便于穷举与差分测试的字段。

直接用浏览器打开 `index.html` 即可，零依赖、无需构建。
