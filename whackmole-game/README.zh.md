# 打地鼠

**[简体中文](README.zh.md)** · [English](README.md)

---

拿起锤子，敲出从草地里冒头的地鼠——小心别敲到炸弹！

## 玩法

- 地鼠会从 9 个洞里随机冒出，点击（或轻触）即可敲中，**+1 分**
- **炸弹 💣** 一眼看上去像地鼠：敲中会 **−3 分**
- 每局 **30 秒**
- 计分板和倒计时就在难度按钮旁边
- 时间到会弹出**结算弹窗**，显示本局得分、击中地鼠数、误击炸弹数和历史最高分（存在 `localStorage`）

## 难度

| 按钮 | 出鼠频率 | 露头时长 |
|---|---|---|
| 悠闲 | 约 1 只/秒 | 约 1.1 秒 |
| 正常 | 约 1.4 只/秒 | 约 0.8 秒 |
| 疯狂 | 约 2 只/秒 | 约 0.56 秒 |

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

游戏顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里，下次打开自动沿用。
