# xiangqi-game · 中国象棋

**[简体中文](README.zh.md)** · [English](README.md)

---

10×9 棋盘中国象棋人机对战，内置 negamax 引擎（Alpha-Beta 剪枝 + 位置价值表）。

## 玩法

- 用浏览器打开 [index.html](index.html) 即可开始
- 点击棋子选中，再点击目标位置落子；你执红先行，电脑执黑
- 难度三档：新手 / 普通 / 高手（对应搜索引擎深度 1 / 3 / 4）
- 勾选「AI先手(黑)」可让电脑执黑先行
- 支持悔棋、重新开始、导出棋谱（txt 下载）

## 规则

- 标准中国象棋走法（蹩马腿、塞象眼、炮打隔子、过河兵横走均已实现）
- 连续将军 3 次判负（长将违规），电脑也会主动规避长将
- 被将死或困毙即结束

## 说明

- 纯前端、零依赖、无任何网络请求，AI 完全在浏览器本地运行
- 棋谱采用观众视角坐标：列 1-9 从左到右，行 1-10 从下到上

游戏顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里，下次打开自动沿用。
