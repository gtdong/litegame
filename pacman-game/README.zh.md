# 吃豆人

**[简体中文](README.zh.md)** · [English](README.md)

---

经典街机追逐游戏。操控吃豆人在迷宫里穿梭，吃光所有豆子、躲开四只幽灵 —— 吃下能量豆就能反客为主，把幽灵反过来吃掉。

## 玩法

- **移动**：方向键或 `W` / `A` / `S` / `D`。按下的方向会被记住，并在下一个路口生效，和街机原版一致；撞到墙就停下。
- **豆子** 每个 10 分，**能量豆** 每个 50 分。吃光棋盘上全部豆子即过关。
- **左右隧道**位于中间一行，吃豆人（和幽灵）可以横向穿行、从另一侧出现。
- **能量豆**：四只幽灵变蓝、减速并强制反向。趁它们变蓝时吃掉，可得 **200 → 400 → 800 → 1600** 连锁分。幽灵恢复前会闪烁白光预警。
- **被吃掉的幽灵**会变成一对眼睛，高速跑回幽灵巢穴，随后重新加入追击。
- **生命**：初始 3 条。在幽灵**未变蓝**时碰到它会掉一条命并播放死亡动画；最后一条命耗尽即游戏结束。

## 四只幽灵

每只幽灵都有各自的追击策略，与街机原版相同：

| 幽灵 | 颜色 | 追击目标 |
|---|---|---|
| **Blinky** | 红 | 吃豆人当前所在格 |
| **Pinky** | 粉 | 吃豆人**前方 4 格** |
| **Inky** | 青 | 以吃豆人位置、经 Blinky 做向量反射（镜像）得到的格 |
| **Clyde** | 橙 | 距离远时追吃豆人，进入 **8 格**内时逃回自己的角落 |

幽灵按关卡时间表在 **Scatter（散开）** 与 **Chase（追击）** 之间交替。每次模式切换会强制反向一次，其余时候幽灵绝不主动掉头。决策完全**确定性**：平局按经典优先级 **上 → 左 → 下 → 右**，因此同一种状态永远得到同一步（方便做穷举测试）。

## 计分

| 事件 | 分数 |
|---|---|
| 豆子 | 10 |
| 能量豆 | 50 |
| 连锁吃幽灵（第 1/2/3/4 只） | 200 / 400 / 800 / 1600 |

## 运行

直接用浏览器打开 `index.html` 即可，零依赖、无需构建。

游戏顶部自带「English / 简体中文」切换，选择会记住。

## 测试桥接

页面在 `window` 上挂了一个稳定的 `PM` 对象，便于无头驱动：

```js
PM.COLS, PM.ROWS, PM.TILE          // 迷宫尺寸与格子大小
PM.maze()                          // 原始迷宫（等长字符串数组）
PM.isWall(r, c)                    // 是否墙体 / 越界
PM.canWalk(r, c)                   // 吃豆人是否可通行（含隧道 wrap）
PM.wrap(r, c)                      // 隧道列坐标归一化 -> { r, c }
PM.ghostTarget(name, mode, st)     // 纯函数：目标格 { r, c }
PM.ghostNextDir(name, st)          // 纯函数：'up' | 'down' | 'left' | 'right'
PM.newGame({ level })              // 重置到完全确定的初始态
PM.getState()                      // { score, lives, level, phase, pelletsLeft,
                                   //   pac, ghosts }
PM.start()                         // 离开「准备」状态开始游戏
PM.tick(seconds[, step])           // 确定性地推进模拟
```

`ghostTarget` 与 `ghostNextDir` 都是纯函数 —— 只依赖入参，不依赖动画帧或画布 —— 可以放心做穷举测试。

处于 **受惊（frightened）** 状态时，幽灵的转向由**确定性伪随机**规则决定（对「幽灵名 + 当前格 + 受惊会话」做哈希），既还原街机里蓝幽灵的随机游走、又保证同参数可复现。
