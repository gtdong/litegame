# 人格测评

**[简体中文](README.zh.md)** · [English](README.md)

---

12 道二选一的题。做完会得到一个四字母类型代号、四条显示你偏向程度的特征条，以及几款适合这一型的本站游戏。

## 玩法

- **12 道题，每个维度 3 道。** 点选项作答，也可以按 **1** / **2**；按 **←**（或「上一题」）改答案。
- 每个维度的题数都是**奇数**，所以任何维度都**不可能平局** —— 一定会得到一个明确的字母。
- 每道题的选项顺序会**随机打乱**，不会出现「某个极永远在左边」；但回退到上一题时**不会**重新打乱你已经读过的选项。

## 四个维度

| 维度 | 两极 | 说的是什么 |
| --- | --- | --- |
| 社交能量 | **E** 向外 / **I** 向内 | 你的能量从哪来 |
| 信息偏好 | **S** 具体 / **N** 可能性 | 你信什么、你会注意到什么 |
| 决策依据 | **T** 逻辑 / **F** 人情 | 关键时候你把什么算进去 |
| 行事风格 | **J** 计划 / **P** 随意 | 你喜欢事情以什么方式摆着 |

代号就是这四个字母按这个顺序拼起来 —— `INFJ`、`ESTP`……覆盖全部 16 种组合。16 型各有自己的名字、一句话和一条值得知道的相处提示。

## 你的结果

结果页会有：**类型代号和名字**、**四条特征条**（带「明显 / 轻微」标记，所以 2–1 和 3–0 读起来不一样）、**你所选四个极各自的说明**，以及**三款**适合这一型的本站游戏。

**复制我的结果**会把一段可以直接发出去的话放进剪贴板。如果浏览器拒绝剪贴板权限，会把这行文字显示出来让你手动复制 —— 不会静默失败。

上一次的结果会存在 `localStorage`，下次打开时在开始页提供给你。

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

页面顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里。

## 这是什么，不是什么

这是一份**原创测评，供娱乐与自我探索**。它不是心理诊断，也不等同于或隶属于任何商业人格量表。之所以用四字母写法，只是因为它正好是「四个二选一维度」一种大家眼熟的记法，仅此而已。

## 测试

`node tools/personality-test.js` —— 104 项断言，分五组：

- **内容完整性** —— 每个维度恰好 3 道题；每个选项的极都与其维度相符；同一题不会有两个一模一样的选项；题目、选项、类型、特征、维度文案**中英双语齐备**，且没有任何一条是「忘了翻译、直接照抄英文」；
- **计分，穷举** —— 把所有 **4096** 种作答组合全部算一遍，证明每个维度都等于 3、任何维度都不可能平局、百分比自洽，并且 **16 个类型代号全都真的能从这套题里答出来**（不是理论上的可能性）；
- **推荐** —— 16 型各自都拿到恰好三款**不重复**的游戏，全都真实存在于磁盘上，推荐池不会指向任何不存在的目录；
- **集成** —— 推荐表里写死的游戏名会与首页卡片逐个比对，改卡片名不会和它悄悄失配；
- **真实 UI** —— 全程走真实的开始按钮、真实的选项点击（走容器事件委托）、真实的上一题按钮和真实键盘处理器，另外还覆盖了剪贴板不可用的降级路径、重新测一次、以及 `localStorage` 内容损坏的情况。

测试里还有一组**反向校验**：把故意改坏的内容副本（删掉一道题、极标错、缺一个翻译、推荐池指向不存在的目录、关闭乱序）喂给同一批校验函数，断言它们**确实会报错**。一个永远不会失败的检查，等于没写。
