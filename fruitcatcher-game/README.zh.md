# 接水果

**[简体中文](README.zh.md)** · [English](README.md)**

---

用篮子接住天而降的水果——别碰到炸弹。这是一款考验时机和协调性的游戏，随着等级提升速度越来越快。

## 玩法

- 水果（🍎🍌🍇🍉🍑🍓）从画布顶部掉落，移动篮子接住它们。不同水果分值不同，越稀有越高
- **炸弹 💣** 混在水果中掉落，接中会扣一条命
- 漏接水果（掉到地上）也扣一条命
- 初始 **3 条命**，命数归零时弹出结算弹窗
- 难度自动提升：生成频率、下落速度、炸弹比例都随等级增加（约每 12 秒升 1 级）

## 控制

- **鼠标 / 触屏**：水平移动篮子
- **←/→** 或 **A/D**：键盘移动
- **空格 / 回车**：暂停 / 继续
- **ESC**：关闭结算弹窗
- **新游戏** 按钮（或弹窗里的「再玩一局」）：开始新一局

## 计分

| 事件 | 效果 |
|---|---|
| 接 🍎🍌🍇 | +10 到 +14 |
| 接 🍉🍑 | +16 到 +18 |
| 接 🍓 | +20 |
| 接 💣 | -1 命 |
| 漏接水果 | -1 命 |

历史最高分存在 `localStorage` 的 `fruitcatcher_best` 键中。

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

游戏顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里，下次打开自动沿用。
