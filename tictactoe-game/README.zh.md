# 井字棋

**[简体中文](README.zh.md)** · [English](README.md)

---

经典 3×3 对弈：抢先把自己的三个棋子连成一线。

## 玩法

- 人机模式你执 **X** 永远先行
- 点击任意空格落子
- 横、竖或斜连成三子即赢下一局
- 两个计数器分别记录 **X 胜场** 和 **O 胜场**

## 模式

| 模式 | 说明 |
|---|---|
| 人机 · 简单 | AI 棋力不错但偶尔失误，可以战胜 |
| 人机 · 困难 | Minimax 全搜索 AI，从不会输，最多逼平 |
| 双人对战 | 同一设备轮流落子，O 后手 |

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

游戏顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里，下次打开自动沿用。
