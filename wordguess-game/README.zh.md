# 猜词

**[简体中文](README.zh.md)** · [English](README.md)

---

六次机会猜出隐藏的词。每次猜测都会逐字给出反馈，把范围一步步收窄到只剩一个答案。

## 玩法

- 页面顶部切换语言，词库会跟着换：**English** 猜五字母单词，**中文**猜四字成语。
- 填满一行后提交。也可以用实体键盘：打字后按 **回车**提交，**退格**删字，**Esc** 开新局。
- 每个格子会给出三种状态之一：

| 颜色 | 含义 |
| --- | --- |
| 🟩 绿色 | 字对，位置也对 |
| 🟨 黄色 | 字在词里，但不在这个位置 |
| ⬜ 灰色 | 词里根本没有这个字 |

- 一共六次机会。猜中就赢，用完就公布答案。

**黄色那条规则是新手第一局最容易误解的：一个字最多只会亮起它在该词里实际出现的次数。** 如果答案里只有一个 `E`，而你猜的词里有三个，那么只有一个是绿或黄 —— 位置完全对上的那个优先，其余都是灰。

## 两种语言，两块独立棋盘

切换语言会切到**那个语言自己的棋盘**，而且**不会重置**任何一边。你切走再切回来，英文局还在原处；两种语言各记各的战绩。两边本来也不该放一起比 —— 五字母单词和四字成语是两种不同的题。

**中文字盘**是这里最讲究的部分。英文有 26 个字母可以直接铺成键盘，中文没有这样一套「字母表」，所以字盘是**从词库本身推出来的**：词库里出现过多少个不同的汉字，就有多少个键，按出现频率从高到低排。这也正是成语表要挑「用字复用率高」的原因 —— 换一份范围更广的成语表，字盘会冲到 200 键以上，每次猜词都变成滚动找字。现在是 130 键。

已经排除掉的字会变暗，所以玩得越久字盘越好读。

## 分享

一局结束后，**复制结果**会把一段不剧透的战绩放进剪贴板：

```
猜词 3/6
⬜⬜🟩⬜🟩
🟨⬜⬜⬜🟩
🟩🟩🟩🟩🟩
https://litegame-hub.github.io/wordguess-game/
```

只有色块，别人无法从中读出答案。如果浏览器拒绝剪贴板权限，同一段文字会显示在文本框里让你手动复制 —— 不会静默失败。

## 关于词库

两套词库都内嵌在页面里，所以整个游戏仍然是一个零依赖的单文件。

- 英文：**635 个可接受的猜词**，答案池 **558** 个常用词。只有词表里的词会被接受 —— 一个拼写正确但不在表里的英文单词会被拒绝，这是「不下载词典」的代价。
- 中文：**52 条常用成语**。

可猜词表刻意比答案池更宽，这样即便某个合理的猜词不可能是答案，也不会被拒。战绩存在 `localStorage` 里；内容损坏时会退化成一份全新战绩，而不是把页面弄坏。

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖和构建步骤。

## 测试

`node tools/wordguess-test.js` —— 117 项断言，分十一组。

其中最关键的是**计分算法的差分测试**。猜词游戏的计分看着简单，其实不是：`命中 / 存在 / 没有` 这三种状态必须正确处理**重复字**，而最经典的错误写法是一遍扫描、只要答案里有这个字就点亮 —— 猜词里出现两次的字会双双亮起。这份测试把上千组猜测同时喂给**两份相互独立实现的计分器**（一份是用「已消耗槽位数组」，另一份是游戏里用的「计数表」），因此两者不可能共用同一个 bug：

- **穷举**全部 256 组「A/B 两字母构成的 4 字串」配对，以及全部 729 组「A/B/C 三字母构成的 3 字串」配对 —— 字母表越小，重复字的情况越密集；
- 8000 组随机的 5 字符 A–D 配对，外加 2000 组真实英文词、2000 组真实成语配对；
- 6000 组随机配对验证**不变量**：一个字亮起的次数恰好等于「它在猜词里出现次数」与「它在答案里出现次数」的较小值，并且答案里没有的字绝不会亮。

其余部分覆盖：词库完整性（长度、字符集、无重复、每个答案都是合法猜词）、字盘（每个不同汉字恰好一个键，且覆盖所有合法猜词的每一个字）、走真实按钮与真实字盘点击的完整流程、战绩与连胜逻辑、剪贴板降级路径、两种语言各自的棋盘状态，以及**双语文案**——标记里要用的 key 一个都不缺、没有漏翻、没有照抄英文，并且两种语言的占位符完全一致。

第 11 组会把**故意造出来的 bug 塞回去**，要求这套测试必须发现，而且每个 bug 都应该由**为它写的那条断言**报出：单遍计分会跨五个组打红 9 项；字盘缺一个字、答案不在可猜词表里、长度不对的词、重复词、中文条目里混入拉丁字母、会泄露字母的分享网格、漏翻、占位符丢失、字典缺 key，则各自被对应断言点名。

### 真实 DOM 复验

`tools/wordguess-dom.js` 是第三层：用 `jsdom` 把页面**真的跑起来**。桩 DOM 没有 `querySelectorAll`、`getAttribute` 恒为 null、`textContent` 也不会汇总子节点，所以上面两套测试**看不见一整类 bug**。这个脚本会去点**真实的**字盘键、按钮和语言链接，并断言真实的棋盘尺寸（英文 6×5、中文 6×4）、真实的字盘键数（26 键 / 130 键）、真实格子的着色，以及切换语言后两边棋盘都原样保留。

它需要 `jsdom`，装在隔离目录里（仓库本身保持零依赖）：

```
NODE_PATH=/Users/dgt/.workbuddy/binaries/node/workspace/node_modules \
  node tools/wordguess-dom.js
```

44 项断言。去掉回车按钮的事件绑定会打红 12 项；让字盘忽略当前语言会打红 3 项；去掉语言切换时的重渲染会打红 5 项。脚本接受一个可选的路径参数，所以这个「反向验证」可以用同一份脚本对故意改坏的副本重跑。
