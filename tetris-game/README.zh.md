# 俄罗斯方块

**[简体中文](README.zh.md)** · [English](README.md)

---

经典下落方块游戏，按现代竞技规则实现——SRS 旋转与踢墙、7-bag 随机器、暂存槽、幽灵落点与 T-spin 检测。

## 玩法

- 方块逐个下落，移动和旋转它们拼满整行即可消除
- 一次消除 1 / 2 / 3 / 4 行分别得 **100 / 300 / 500 / 800** 分（× 等级）
- 新方块无法进入场地时游戏结束

## 操作

| 按键 | 功能 |
|---|---|
| `←` `→` | 左右移动 |
| `↑` 或 `X` | 顺时针旋转 |
| `Z` | 逆时针旋转 |
| `↓` | **一键贴地** —— 直接落到该列最底，但**不锁定**，落下后仍可左右微调；已贴地时再按一次即锁定 |
| `S` | 软降，按住加速下落（每格 +1 分） |
| `Space` | 硬降 —— 瞬间落定（每格 +2 分） |
| `C` | 暂存 / 交换当前方块 |
| `P` | 暂停 / 继续 |
| `R` | 新游戏 |
| `-` `=` | 调慢 / 调快一档速度 |
| `Esc` | 关闭弹窗 |

触屏设备在棋盘下方有独立的按钮操作区。

三个"往下"的键刻意做成不同手感：

| 按键 | 手感 | 计分 | 可反悔 |
|---|---|---|---|
| `S` | 加速下落，逐格推进 | 每格 +1 | 可以 |
| `↓` | 一键贴到列底 | 不计分 | 锁定前可以微调 |
| `Space` | 瞬间落定并锁定 | 每格 +2 | 不行 |

## 特性

- **SRS 旋转系统** —— 完整实现 Super Rotation System，包含 JLSTZ 与 I 两套踢墙表。方块贴墙时会被"踢"出来而不是拒绝旋转
- **7-bag 随机器** —— 每 7 个方块恰好包含全部 7 种形状各一次，不会长时间不出 I 块
- **暂存槽（Hold）** —— 把方块存起来备用，每个方块限用一次
- **5 格预览** —— 提前看到后面 5 个方块
- **幽灵方块** —— 用轮廓标出当前方块的落点
- **T-spin 检测** —— 用三格角规则识别 T-spin，最高可得 1600 分
- **连击计数** —— 连续消行每次追加 `50 × 连击数 × 等级` 分
- **等级加速** —— 每消 10 行升 1 级，下落间隔从 800ms 逐步逼近 55ms 下限
- **手动调速** —— 在等级曲线之上再叠加 0.5× / 1× / 2× / 3× 倍率，棋盘下方一行按钮或 `-` / `=` 随时切换，选择会被记住

历史最高分存在 `localStorage` 的 `tetris_best` 键中。

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

打开后会先显示开始界面，点 **开始游戏**（或按 `Space` / `Enter`）方块才会开始下落。棋盘下方的 **新游戏** 按钮可随时重开。

游戏顶部自带「English / 简体中文」切换，选择会记在 `localStorage` 里，下次打开自动沿用。
